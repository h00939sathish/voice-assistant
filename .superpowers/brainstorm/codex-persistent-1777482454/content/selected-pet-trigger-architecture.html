AionUi subscribes to Jarvis state events over WebSocket/SSE and maps them to pet animations.

First slice includes

  • Companion wake endpoint for AionUi.
  • State event feed for pet animation mapping.
  • Minimal click-to-talk path using existing Jarvis microphone logic.
